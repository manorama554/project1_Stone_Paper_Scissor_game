🪨 Stone Paper Scissor Game

A simple command-line Stone Paper Scissor game built using Python. The game allows a player to compete against the computer, with the winner determined based on the classic game rules.

🚀 Features

Play against the computer
Random computer choices using Python's random module
User-friendly input
Displays the winner after each round
Simple and easy-to-understand Python code
🛠️ Technologies Used

Python
Random Module

🎮 Game Rules

🪨 Stone beats Scissors
✂️ Scissors beat Paper
📄 Paper beats Stone
If both players choose the same option, the game is a draw.
📸 Sample Output

Enter your choice (s/p/g): s

You chose: Stone
Computer chose: Paper

You Lose!
